PLASTIR RD ArchVis 2.0

Arquitectura de Producción: Storefront (plastirrd.com) vs ERP Odoo 18 (app.plastirrd.com)

Veredicto: Subdominio app.plastirrd.com

  • Aislamiento de WebSockets: Odoo 18 corre /websocket en la raíz sin romper las rutas de la tienda.
  • Cero colisiones de assets: Los archivos de /web/assets de Odoo no interfieren con Vite o React.
  • Cookies y Sesiones seguras: Las sesiones del personal del ERP nunca se filtran al navegador del comprador.
  • Configuración limpia en Nginx: Cada dominio tiene su propio bloque server { ... } estándar.

¿Por qué NO usar plastirrd.com/odoo?

  • Ruptura de WebSockets: El cliente web de Odoo llama a wss://plastirrd.com/websocket en la raíz, chocando con el frontend.
  • Colisiones de URLs: Odoo pide /web/content y /web/image, pisando el router del frontend.
  • Reescrituras frágiles: Requiere módulos sub_filter de Nginx que se rompen con gzip o actualizaciones de Odoo.

Certbot SSL Automático

  • Con un solo comando de Certbot se obtienen los certificados SSL para ambos dominios:
  • certbot --nginx -d plastirrd.com -d www.plastirrd.com -d app.plastirrd.com
  • Renovación automática cada 90 días mediante systemd cron de Let's Encrypt.
